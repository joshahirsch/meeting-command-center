# Meeting Ops Automation — Setup Guide

## Prerequisites

1. **Node.js 18+** installed locally.
2. **Google account** with access to the target Gmail, Drive, Sheets, and Apps Script project.
3. **[clasp](https://github.com/google/clasp)** — installed via `npm install` in this repo.
4. **Apps Script project** — create at [script.google.com](https://script.google.com) or via `clasp create`.
5. **Master Google Sheet** — create a spreadsheet named **Meeting Action Master** (or any name; you will use its ID).
6. **Gemini Meet source folder** — the Drive folder where Google Meet saves notes and recordings (read-only for this automation).
7. **Output Drive folder** — create a folder for summary Google Docs generated by Meeting Ops.
8. **OpenAI API key** — with access to the Responses API and your chosen model.

## Local install

```bash
cd meeting-ops-automation
npm install
cp .clasp.example.json .clasp.json
```

Edit `.clasp.json` and set `scriptId` to your Apps Script project ID. **Do not commit `.clasp.json`.**

## Build and deploy code

```bash
npm run build
clasp login   # if not already logged in
npm run push
```

`npm run push` runs the build and uploads `dist/Code.js` and `dist/appsscript.json`.

## Script properties (Apps Script)

In the Apps Script editor: **Project Settings → Script properties**, add:

| Property | Required | Example / default |
|----------|----------|-------------------|
| `OPENAI_API_KEY` | Yes | (secret — never commit) |
| `OPENAI_MODEL` | No | `gpt-4.1-mini` |
| `ACTION_SHEET_ID` | Yes | Spreadsheet ID from URL |
| `OUTPUT_FOLDER_ID` | Yes | Drive folder ID for summary docs |
| `SOURCE_MODE` | No | `drive` (recommended) or `gmail` |
| `SOURCE_FOLDER_ID` | Yes for Drive | e.g. `1OU99p91VvHrSEuX9TTINmYHXlweojaNh` |
| `DRIVE_LOOKBACK_DAYS` | No | `14` |
| `MAX_FILES_PER_RUN` | No | `3` |
| `PROCESS_RECORDINGS` | No | `false` |
| `INCLUDE_RECORDING_LINK` | No | `true` |
| `TARGET_LABEL_NAME` | No | `Gemini Meeting Notes` (Gmail mode) |
| `PROCESSED_LABEL_NAME` | No | `Meeting Ops Processed` |
| `ERROR_LABEL_NAME` | No | `Meeting Ops Error` |
| `MAX_THREADS_PER_RUN` | No | `3` (Gmail mode) |
| `LOOKBACK_DAYS` | No | `14` (Gmail mode) |
| `NOTIFICATION_EMAIL` | No | your email |
| `FORCE_PROCESS_TEST_MODE` | No | `false` (set `true` only for forced reprocessing tests) |
| `CREATE_TARGET_LABEL_IF_MISSING` | No | `false` |

If `SOURCE_MODE` is omitted, the script uses **drive** when `SOURCE_FOLDER_ID` is set, otherwise **gmail**.

### Recommended Drive configuration

```text
SOURCE_MODE=drive
SOURCE_FOLDER_ID=1OU99p91VvHrSEuX9TTINmYHXlweojaNh
DRIVE_LOOKBACK_DAYS=14
MAX_FILES_PER_RUN=3
INCLUDE_RECORDING_LINK=true
PROCESS_RECORDINGS=false
```

The automation **does not** move, rename, delete, or edit files in the source folder.

## Gmail labels (fallback mode only)

- Apply **Gemini Meeting Notes** to incoming Gemini notes emails.
- **Meeting Ops Processed** — created by setup/run if missing.
- **Meeting Ops Error** — created automatically if missing.

Drive mode does not use Gmail processed labels.

## OAuth scopes

On first run, Apps Script will request authorization for Gmail, Drive, Docs, Sheets, and external HTTP (OpenAI). Approve with the same account that owns the mailbox, source folder, and assets.

## First-time run order (Drive — recommended)

Run these functions manually from the Apps Script editor (or via clasp run):

1. `showConfigStatus` — verify properties (secrets hidden).
2. `setupMeetingOpsSheets` — create tabs and append any missing headers.
3. `dryRunLatestDriveMeetingNote` — extract + OpenAI without sheet writes.
4. `processOneDriveFileById` — pass the Google Doc file ID of one `Notes by Gemini` file.
5. `installMeetingOpsTrigger` — enable scheduled runs (`runMeetingOps` uses Drive when `SOURCE_MODE=drive`).

## First-time run order (Gmail fallback)

1. `showConfigStatus`
2. `setupMeetingOpsSheets`
3. `dryRunLatestMeetingNote` (with `SOURCE_MODE=gmail` or no `SOURCE_FOLDER_ID`)
4. `processOneThreadById` — pass a known `threadId`
5. `installMeetingOpsTrigger`

## Disable automation

```text
removeMeetingOpsTriggers()
```

Optionally pause by removing OpenAI or sheet script properties.
